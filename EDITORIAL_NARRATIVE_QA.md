# Mythos Atlas — Narrative Quality Gate (StoryScope-informed)

## Purpose
This gate is an editorial QA layer for Mythos Atlas. It is not an AI-detector and it does not treat rarity as quality. It uses StoryScope's reported narrative tendencies as failure modes to check while preserving the project's first priority: source fidelity.

## Non-negotiable source rules
- Preserve [A]/[B]/[C]/[D] evidence grades.
- Never invent dialogue, motive, sensory detail, chronology, or causal links that the ancient evidence does not support.
- Earlier surviving attestation is not proof of earlier origin or direct borrowing.
- Keep textual variants, lacunae, contradictions, and scholarly uncertainty visible instead of silently harmonizing them.
- Cross-cultural parallels require chronology, difference, contact plausibility, and archaeological/textual limits.

## Narrative failure modes to avoid
1. Thematic over-explication: do not explain the theme after every scene. Prefer evidence and juxtaposition; let readers infer.
2. Causal over-tidiness: do not convert fragmentary or contradictory traditions into one frictionless chain.
3. Single-track plotting: when historically relevant, weave prior characters, parallel traditions, artifacts, or consequences through the main episode rather than placing all context in a detached appendix-like block.
4. Chronological monotony: chronology remains the backbone, but short evidence-driven retrospection, foreshadowing, or delayed revelation may be used when it improves recontextualization. Never add complexity merely to look literary.
5. Moral over-resolution: do not decide for the reader that a character is simply right/wrong when the sources preserve competing obligations or interpretations.
6. Overclosure: avoid ending every episode with a thesis-summary and a fully resolved lesson. Preserve an unresolved textual problem, consequence, or narrative pressure that genuinely leads onward.
7. Decorative embodiment: sensory or bodily-emotion description must come from the source or clearly marked reception material, not generic atmospheric invention.
8. Formula repetition: avoid recurring scaffolds such as “the key is…”, “what this scene tells us…”, repeated boxed morals, or identical paragraph rhythms across episodes.

## Preferred episode movement
Use a flexible braid rather than a fixed template:
- concrete ancient scene or textual problem
- source evidence and its limits
- a return to an earlier thread or a secondary figure
- a cross-cultural comparison only where it changes the reader's understanding
- archaeology/material culture where it constrains or complicates the story
- return to the scene with changed context
- leave the next genuine pressure point open

Do not force every episode to contain all of these in the same order.

## Pre-publication critic
Before publishing, ask:
- Is the theme stated more often than necessary?
- Did we “solve” a contradiction that the sources do not solve?
- Is the plot effectively one clean line with all context appended afterward?
- Is there a relevant secondary thread that can recontextualize the main scene?
- Are comparisons integrated at the moment they matter?
- Did we manufacture ambiguity or nonlinear structure merely to score as “human”?
- Did we turn moral ambiguity into a verdict?
- Does the ending explain everything twice?
- Are sensory details actually sourced?
- Are sentence/paragraph transitions repeating the same AI-like pattern?
- Does the reader still have interpretive work to do?
- Are all factual claims and image/licensing claims traceable?

If any answer exposes a problem, rewrite before commit.

## Retrospective pass for Episodes 1–35
The existing corpus should be revised without changing episode numbering, URLs, evidence grades, source notes, or verified image metadata. For each KO/EN pair:
1. preserve all supported factual content;
2. remove redundant thesis-explanation and duplicated conclusions;
3. restore unresolved variants and uncertainty where prior prose over-harmonized;
4. braid comparison/archaeology into the relevant narrative moments;
5. recover earlier foreshadowing and create only evidence-based forward pressure;
6. preserve KO/EN information parity;
7. verify navigation and representative image/source/license;
8. run the critic above.

A revision is complete only when both language files have been reviewed together. Do not mark an episode revised merely because surface wording changed.

## Future episodes
Every new episode must pass this gate before the normal publishing set is committed. StoryScope-inspired checks are a QA constraint, not an objective function: rarity != creativity, complexity != quality, and source fidelity always outranks stylistic novelty.
